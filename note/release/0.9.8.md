# 0.9.8 — AI 注意力占用优化第二轮(轮 11-13)

日期:2026-09-30 · 上一版:0.9.7(文档对齐)

## 背景

延续 0.9.6 的注意力战役:红线(安全/稳定/兼容)不破,继续压缩插件注入模型上下文的
全部文本面。本轮以 v0.9.7 为冻结基线(`benchmark/baseline-v0.9.7/`),三轮各一个
独立优化点,并新增按需面(命令文件/SKILL 正文)的量化测量。

## 决策

- **轮 11(每轮注入)**:命令四段缩短——`ZSID` 短环境别名(脚本新增等价别名)、
  `-c` 组合短旗标(= `--turn --current`)、短路径副本改名 `~/.zcode/tr.mjs`(升级时
  自动清理旧名)、指令措辞去冗词;CLI 守卫改基名白名单(与路径风格无关)。
- **轮 12(一次性面)**:session-start 提示与 MCP 描述去冗余;SKILL frontmatter
  触发描述**有意不动**——触发关键词是技能召回依据,~6 tok 不值得换可靠性。
- **轮 13(按需面)**:bench-attention 新增 commands/skillBody 两面;命令文件与
  SKILL 正文收紧,行为语义全保留。

## 验证

- `node --test` 21/21;bench-attention:perTurn ×1.18、session ×1.21、tools ×1.10、
  commands ×1.27、skillBody ×1.04、百轮常驻面 11,102→9,401(×1.18)。
- 运行时回归门 `run-all` 六基准全绿无回退(prompt-submit ×0.996 噪声带内)。
